# Tito

Tito's learning and personal note-taking space as a TSAP editor.

## Why this repository exists

This repository keeps Tito's personal learning notes, experiments, working knowledge and documentation in one place.

Some of this learning is connected to the work and progress taking place around the Sunil Abraham project and TSAP. However, not everything Tito learns or works on belongs in the main Sunil Abraham repository. Keeping these materials separate avoids mixing personal learning records with the project's published website, articles and other official project content.

The repository provides a separate space to document useful learning and practical work that may support, inform or contribute to TSAP-related work, without placing every note or experiment in the main project repository.

## Why it is public

The repository is public because its contents are intended to be general learning notes and documentation, not confidential material. Making it public also allows other people to discover the notes and learn from the documented work.

Do not use this repository for passwords, private credentials, personal data or confidential project information.

## Organisation

Notes are organised primarily by subject. For example, learning about graphics software such as Inkscape belongs under the `graphics/` folder. Other subject folders can be added as learning areas grow.

The aim is to keep the structure simple and practical. Notes can record what was learned, useful commands or methods, problems encountered, decisions made and relevant links, so that work can be resumed later without depending on the memory of a particular ChatGPT conversation.

## Continuity

This repository is also a durable record of learning across sessions and conversations. When a discussion produces useful knowledge or decisions, documenting them here helps preserve the context. A future session can consult the relevant notes and continue from the recorded progress.

The repository itself is the reference point; individual ChatGPT conversations are working sessions, not the permanent record.
